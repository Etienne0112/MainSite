# Everything of My Workspace

DesertRose's Blog, Study Archive와 앞으로 추가할 개인 사이트를 한곳에서 연결하는 메인 디렉터리입니다.

## 현재 연결된 사이트

- [DesertRose's Blog](https://etienne0112.github.io/DesertRose-s-Blog/)
- [Study Archive](https://etienne0112.github.io/Study/)

전체 디렉터리는 라이브 사이트 2개와 확장용 예약 슬롯 18개, 총 20개 카드로 구성됩니다.

## 로컬 실행

```bash
npm install
npm run dev
```

`main` 브랜치에 반영된 변경은 GitHub Actions를 통해 GitHub Pages로 배포됩니다.
